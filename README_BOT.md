# 🎮 Pac-Rush Auto Gameplay Bot & Note Logger

An intelligent autonomous gameplay bot and logger for the **Pac-Rush** game (Construct 3 HTML5 engine).

---

## 📌 Game Analysis (সম্পূর্ণ গেম অ্যানালাইসিস)

### ১. গেমের ধরন ও ইঞ্জিন (Engine & Type)
* **Engine:** Scirra Construct 3 (HTML5 Canvas / WebGL).
* **Mode:** Single-threaded DOM execution (`useWorker: false`), ৭২০x১২৮০ রেজোলিউশন (Portrait).
* **Scenes / Layouts:**
  - `START`: টাইটেল ও স্প্ল্যাশ স্ক্রিন। ক্লিক/ট্যাপ করলেই `L1` (লেভেল ১)-এ চলে যায়।
  - `L1`: মূল গেমপ্লে স্ক্রিন।
  - `OBJECTS`: গেম অবজেক্ট টেমপ্লেট।

### ২. অবজেক্ট এবং কোঅর্ডিনেট সিস্টেম (Coordinates & Objects)
* **Center Point:** `(X: 360, Y: 650)` — ট্র্যাকের কেন্দ্রস্থল।
* **Circular Track:** 
  - `circle1` (আউটার বাউন্ডারি): ব্যাসার্ধ ২৪৫ পিক্সেল।
  - `circle2` (ইনার বাউন্ডারি): ব্যাসার্ধ ১৬০ পিক্সেল।
  - `ball` (প্লেয়ার ক্যারেক্টার): ব্যাসার্ধ ১৮৫ পিক্সেল দূরে বৃত্তাকার ট্র্যাকে ঘোরে।
* **ballspeed:** অদৃশ্য স্পিড কন্ট্রোলার (Rotate behavior), যা ক্লকওয়াইজ বা কাউন্টার-ক্লকওয়াইজ ডিরেকশনে ঘোরে।
* **point:** স্কোরিং ডট / খাবার (৬০x৬০ পিক্সেল), যা ট্র্যাকে এলোমেলো অ্যাঙ্গেলে স্পন হয়।
* **create & obstacle:** স্ক্রিনের উপর থেকে (`Y = -200`) সোজা নিচের দিকে (Bullet Speed) বাধাগুলো পড়তে থাকে।

### ৩. গেম মেকানিক্স ও রুলস (Mechanics & Controls)
* **কন্ট্রোল:** সম্পূর্ণ গেমটিতে শুধুমাত্র **১টি ইনপুট** প্রয়োজন — টাচ, ক্লিক অথবা **Spacebar**।
* **মুভমেন্ট:**
  - গেম শুরুর প্রথম ক্লিকে বলটি ঘোরা শুরু করে (`GO = 1`)।
  - এরপর প্রতিটি ক্লিকে বলের ঘূর্ণনের দিক পরিবর্তিত হয় (Clockwise ⟷ Counter-Clockwise)।
* **স্কোরিং:** বল যখন `point` (হলুদ ডট) স্পর্শ করে, স্কোর +১ বাড়ে এবং পয়েন্টটি ট্র্যাকে নতুন অ্যাঙ্গেলে চলে যায়।
* **গেম ওভার:** বল যদি কোনো পড়ন্ত `obstacle` (বাধা)-র সাথে ধাক্কা খায়, সাথে সাথে গেম ওভার হয় এবং স্কোর এনক্রিপ্ট হয়ে সার্ভারে সাবমিট হয়।

## 🤖 বট কীভাবে কাজ করে (Bot Architecture)

1. **অটো স্টার্ট ও নেভিগেশন (Auto Start):**
   - গেম ওপেন হলে `START` স্ক্রিন থেকে অটো ক্লিক করে গেমপ্লেতে প্রবেশ করে।
   - বল থেমে থাকলে প্রথম ক্লিক করে ঘূর্ণন শুরু করে।
2. **ট্র্যাজেক্টরি প্রেডিকশন ও ডজ (Predictive Evasion AI):**
   - বলের বর্তমান কোণ ($\theta$), ঘূর্ণন গতি ($\omega$) এবং প্রতিটি বাধার নামার বেগ ($v_y$) ক্যালকুলেট করে।
   - আগামী ০.৮ সেকেন্ডে বল যদি বর্তমান দিকে চলে তবে সংঘর্ষ হবে কি না তা পরিমাপ করে।
   - একইসাথে বিপরীত দিকে গেলে সংঘর্ষ হবে কি না তাও পরীক্ষা করে।
   - বিপদ দেখলে সাথে সাথে ক্লিক করে দিক পরিবর্তন করে বলকে বাঁচায়।
3. **পয়েন্ট টার্গেটিং (Point Seeking):**
   - যখন কোনো বাধা সামনে থাকে না, তখন বট হিসাব করে কোন দিকে ঘুরলে সবচেয়ে দ্রুত `point` (খাবার) পাওয়া যাবে এবং সেদিকে দিক পরিবর্তন করে।
4. **সেফটি শিল্ড (God Mode / Shield Toggle):**
   - কোনো বাধা যদি এমনভাবে পড়ে যা গণিতানুযায়ী এড়ানো অসম্ভব, তবে শিল্ড সিস্টেম বলকে তাৎক্ষণিক সুরক্ষিত রাখে, যাতে বট ঘন্টার পর ঘন্টা না মরে খেলতে পারে।
5. **অটো রিস্টার্ট (Auto Restart):**
   - কোনো কারণে গেম ওভার হলে ১ সেকেন্ডের মধ্যে অটো রিস্টার্ট করে খেলা চালিয়ে যায়।
6. **অন-স্ক্রিন HUD:**
   - গেমের উপরে একটি সাইবারপাঙ্ক স্টাইলের ড্যাশবোর্ড থাকে যেখানে লাইভ টাইম, ক্লিক সংখ্যা, স্কোর এবং বটের স্ট্যাটাস দেখা যায়।
   - কিবোর্ডে `B` চাপলে বট Pause / Resume করা যায়।

## 📝 note.txt লগিং সিস্টেম (Auto Note Logger)

ব্যবহারকারীর নির্ধারিত ফরম্যাট অনুযায়ী স্বয়ংক্রিয়ভাবে ডাটা সংরক্ষণ হয়:

```
Time - Click - Score 
 1m 2s - 20 -  300
```

* **স্বয়ংক্রিয় লগ:** প্রতি ১ মিনিট পর পর (১ম মিনিট, ২য় মিনিট, ৩য় মিনিট...) এবং গেম শেষ হলে স্বয়ংক্রিয়ভাবে একটি নতুন লাইন `note.txt`-এ যুক্ত হয়।
* **ডিরেক্ট ফাইল সেভ:** লোকাল সার্ভারের মাধ্যমে এটি সরাসরি আপনার লোকাল `note.txt` ফাইলে রিয়েল-টাইমে সেভ হয়।
* **ম্যানুয়াল ডাউনলোড:** গেমের HUD-এর **💾 Save note.txt** বাটনে ক্লিক করেও যেকোনো সময় ফাইলটি ডাউনলোড করা যায়।

## 🚀 কীভাবে বট চালাবেন (How to Run)

### অপশন ১: এক ক্লিকে চালানো (Recommended)
`start_bot.bat` ফাইলে ডাবল ক্লিক করুন, অথবা টার্মিনালে রান করুন:
```bash
python start_bot.py
```
* এটি স্বয়ংক্রিয়ভাবে লোকাল সার্ভার চালু করবে।
* ব্রাউজারে গেম ওপেন করবে (`http://localhost:8080`)।
* বট স্বয়ংক্রিয়ভাবে খেলা শুরু করবে এবং টার্মিনালে `note.txt`-এর লাইভ আপডেট দেখাবে।

### অপশন ২: ম্যানুয়াল রান
```bash
# ১. সার্ভার চালু করুন
python server.py

# ২. ব্রাউজারে যান
http://localhost:8080
```

## 💀 গেম ওভার রিডাইরেক্ট ও হিস্টোরি (Game Over Screen)

* **রিডাইরেক্ট পাথ:** `game-over/` (`game-over/index.html`)
* **কার্যপদ্ধতি:** গেম ওভার হওয়ার সাথে সাথে:
  1. খেলার সময় (Time), মোট ক্লিক (Clicks), এবং স্কোর (Score) স্বয়ংক্রিয়ভাবে `note.txt`-এ আগের ডাটার নিচে যুক্ত হয়।
  2. ব্রাউজার স্বয়ংক্রিয়ভাবে `game-over/` ফোল্ডারে রিডাইরেক্ট হয়।
  3. গেম ওভার পেজে পূর্ববর্তী সকল রেকর্ডের হিস্টোরি দেখা যায় এবং **Play Again** বাটনে চাপ দিয়ে পুনরায় নতুন গেম শুরু করা যায়।
